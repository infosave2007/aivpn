# AIVPN Client: Google Play review media

`aivpn-play-review-demo.mp4` (59 s) shows the Android app for the Google Play declarations of AIVPN Client 1.3.1 (`com.aivpn.client`):

- VPN service: the app is opened, connects to the AIVPN server from its connection key (shown here as `vpn.example.com`), and a web page loads through the tunnel.
- Package visibility (`QUERY_ALL_PACKAGES`): Split Tunneling > Apps lists installed apps; Chrome is picked to use the VPN.
- Foreground service (special use): the VPN service stays connected while the user switches to Chrome.

This branch holds review media only and shares no history with the source code.
